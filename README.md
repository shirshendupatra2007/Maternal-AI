# 🌸 Maternal-AI — 3D Maternal Companion & Upgraded Health Dashboard

An ultra-modern, empathetic, full-stack 3D maternal health companion and pregnancy management suite built with **React 19, Three.js WebGL, Node.js, Express, and Google Gemini AI**.

---

## ✨ Upgraded 3D & Clinical Highlights

- **🌐 Interactive 3D Gestational Environment (Three.js WebGL)**:
  - Real-time 3D pulsing embryo core with soft maternal stardust and orbiting trimester rings.
  - Interactive mouse & touch orbit control with dynamic lighting and specular reflections.
- **💓 3D Fetal Heartbeat & Doppler Rhythm Simulator**:
  - Live animated Doppler ECG pulse wave with fetal BPM estimation.
  - Interactive 3D tactile kick counter with celebratory particle physics.
  - Trimester development comparisons (Baby size, estimated weight, and vegetable/fruit analogies).
- **💧 3D Interactive Hydration Tumbler**:
  - Realistic fluid level wave simulation, bubble animations, and specular glass refractions.
  - Quick `+250ml` and `+500ml` logging with confetti bursts upon reaching the daily 2,500ml target.
- **✨ Dynamic Card3D Tilt with Specular Glare**:
  - Dashboard cards smoothly tilt in 3D perspective with moving light glare based on cursor position.
- **💊 3D Pill Capsule & Medication Adherence**:
  - Realistic two-tone 3D gelatin capsule graphics for scheduled medications.
  - Tactile 3D push buttons with haptic depression animations.
  - 30-day adherence tracking with celebratory milestone confetti.
- **🥗 Upgraded 3D Nutrition Suite**:
  - 3D Macro Gauge cards for Energy, Protein, Elemental Iron, and Calcium.
  - Daily Nutrient Requirement table with clinical AI recommendations.
  - Meal intake comparison against RDA targets (Carbohydrates, Fats, Proteins, Iron, Fiber, Calcium, Water) with Deficient / Normal / Excess badges.
- **🤖 Live Google Gemini AI Doctor Integration**:
  - Real obstetrician & nutritionist prompt architecture powered by `@google/genai` (Gemini Flash).
  - Multi-turn conversational consultation with clinical memory.

## 🚀 Quick Start

### Option 1: Double-Click Startup
Double-click `START.bat` in the root folder to start both backend and frontend servers simultaneously.

### Option 2: Terminal Run

#### Backend:
```bash
cd backend
npm install
node server.js
```
*Backend runs on port 5000 (`http://localhost:5000`)*

#### Frontend:
```bash
cd frontend
npm install
npm run dev
```
*Frontend runs on port 5173 (`http://localhost:5173`)*

---

## 🔑 Environment Configuration

Create a `.env` file in the `backend/` directory (see `backend/.env.example`):
```env
GEMINI_API_KEY=your_gemini_api_key_here
JWT_SECRET=maternal_health_super_secret_jwt_2024
PORT=5000
NODE_ENV=development
```

## 🛠️ Tech Stack

- **Frontend**: React 19, Three.js (WebGL 3D), Vite, React Router DOM, Recharts, Lucide Icons, Canvas-Confetti, React Hot Toast
- **Design System**: Light Glassmorphism, 3D Perspective Tilt, Neumorphic input fields, soft pastel glow, mobile-first responsive layout
- **Backend**: Node.js, Express, LowDB, JWT, BcryptJS
- **AI**: Official Google GenAI SDK (`@google/genai`) with Gemini Flash
